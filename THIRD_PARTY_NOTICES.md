# Third-Party Software

This project is MIT-licensed (see [`LICENSE`](LICENSE)). It also depends on
other open-source software, listed here in full for anyone reviewing this
repo before using or redistributing it.

Two categories:

- **Bundled dependencies** — npm packages actually imported into the running
  Node app (`server/`), pulled in via `npm install` and pinned in
  `server/package-lock.json`.
- **Infrastructure** — separate system software the deployment installer
  (`infra/install.sh`) installs alongside the app (a TLS proxy, a TURN
  server, etc.). Not bundled or redistributed by this repo — installed from
  each project's own official package/distribution.

## Infrastructure (installed by `infra/install.sh`, not bundled)

| Software | Role in this deployment | License |
|---|---|---|
| [Node.js](https://nodejs.org/) | Runs the application | MIT |
| [Caddy](https://caddyserver.com/) | TLS termination, reverse proxy | Apache-2.0 |
| [coturn](https://github.com/coturn/coturn) | TURN/STUN relay for WebRTC media | BSD-style |
| [Certbot](https://certbot.eff.org/) | TLS certificate issuance (Let's Encrypt) | Apache-2.0 |
| [fail2ban](https://github.com/fail2ban/fail2ban) | Brute-force ban on repeated auth failures | GPL-2.0 |
| [ufw](https://launchpad.net/ufw) | Host firewall | GPL-3.0 |
| [OpenSSH](https://www.openssh.com/) | Remote administration | BSD-style |
| [rsync](https://rsync.samba.org/) | Deploying app files to `/opt` | GPL-3.0 |
| unattended-upgrades | Automatic OS security patching | GPL |

None of the above ships inside this repo or the running Node process — they're
separate system packages the installer pulls from Ubuntu's own repositories
(or, for Caddy, its official apt repository) and Let's Encrypt. Using them as
standalone system services doesn't trigger any redistribution obligations
under their licenses, GPL included.
